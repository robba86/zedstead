# Roadmap

What is planned for Zedstead, and what is not. There are no dates. The order inside a group is a rough priority, not a promise.

Each item has a fixed id (R1, R2 ...) that is the same in `ROADMAP.md` and `plans/ROADMAP.md`. An id never changes when the order changes. A new item takes the next free id.

A bug that breaks a server or loses data does not wait for this list: report it as an [issue](https://github.com/robba86/zedstead/issues).

## Not planned

1. **Console servers (PS4/Xbox)**: the licence is exclusive to one host.
2. **Uptime guarantees, 24/7 support, hardware**: that is a hosting company's product.
3. **Telemetry that is on by default**: the server list and the install counter are opt-in.
4. **Its own DDoS protection**: that belongs with the VPS provider.
